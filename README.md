### Selected work 🤖

- **Telepresence Robot:** ROS-based LiDAR/IMU SLAM, AMCL localization, autonomous navigation and Arduino control. Approximately 95% mapping accuracy and below 5 cm localization error in controlled tests.
- **Autonomous UGV:** GPS/IMU waypoint navigation using a Kalman Filter and PID control. Improved tested positioning from approximately ±3 m to below 50 cm.
- **Embedded Linux and Secure OTA:** Yocto-based ARM platform using RAUC A/B updates, containerd and GitLab CI/CD. Approximately 17 MB idle RAM and CI builds reduced from roughly 2.5 hours to 5–10 minutes.
- **Face Recognition:** Local real-time perception system using InsightFace, ONNX Runtime and OpenCV.
- **IIoT Anomaly Detection:** Edge anomaly-detection prototype using Isolation Forest and MQTT.

### Current focus 🚀

Autonomous mobile robots, ROS2/Nav2, perception, SLAM, behavior validation, and dependable software deployment onto physical systems.
